## 👨‍💻 Sobre Mí

Soy **Gerson Misael Pintado Huamán**, desarrollador de software de **Sullana, Piura (Perú)** 🇵🇪. Me especializo en crear aplicaciones web completas, sistemas de gestión institucional e interfaces modernas y accesibles.

* 💻 **Desarrollo Web:** JavaScript (ES6+), TypeScript, Node.js, Python, PHP y Laravel.
* 🔐 **Seguridad & Arquitectura:** Autenticación con JWT, cifrado con SHA-256, diseño de APIs REST y bases de datos relacionales/NoSQL.
* 🚀 **Experiencia Práctica:** Creador de la Intranet I.E. 14739, la plataforma de prevención de riesgos ARGOS y proyectos multimedia interactivos.
* 💼 **Red Profesional:** Conectemos en [**LinkedIn (Misael Pintado)**](https://www.linkedin.com/in/misael-pintado-huaman-63b7b3423).
